Three Operating Modes

From standalone orbit modeling to physical RTK receiver streaming

Mode 0

🛰️ Internal + TLE

Operates with zero external hardware using native device CoreLocation and live CelesTrak SGP4 24-hour Keplerian orbit propagators with a $\pm 12\text{h}$ time slider.

Mode 1

📡 Bluetooth Low Energy

Direct wireless connection via Nordic UART Service (NUS) to the physical ESP32 bridge. Streams live NMEA sentences and paced Galileo I/NAV frames without Apple MFi locks.

Mode 2

🌐 UDP Telemetry / SDR

High-performance UDP listener on port 9090 receiving live IQ synthesized telemetry from HackRF One, gnss-sdr, or the internal in-process Swift generator.
